# 05 - Visual Perception

## 目标
为小车部署完整的视觉感知系统，使其能够实时识别环境中的障碍物类别、位置和距离。感知模块是避障决策的输入源，也是整个系统"感知-决策-执行"闭环的第一环。

## 核心技术

### 目标检测（YOLOv8）
- 使用 YOLOv8n 模型对摄像头画面进行实时目标检测。
- 能够识别室内环境中常见的 80 类物体（椅子、桌子、人等）。
- 检测帧率约 30fps（笔记本 CPU）。

### 深度估计（MiDaS）
- 基于 MiDaS_small 单目深度估计模型，从单张 RGB 图像中推断每个像素的相对深度。
- 手动预处理替代 transforms 库，解决了维度不兼容问题。
- 通过经验标定参数（KNOWN_DEPTH_AT_1M = 150）将深度值转换为近似的米制距离。

### 感知融合
- 将 YOLO 检测结果与深度估计结果融合：提取每个检测框中心区域的深度平均值，换算为距离（米），标注在检测框旁边。
- 系统同时输出障碍物的类别、置信度和距离信息，为后续避障决策提供完整的感知输入。

## 关键问题与解决

### 1. 透明物体检测失效
- **问题**：无色透明水杯在深度图中无法被检测，深度图显示为背景而非物体。
- **原因**：透明物体不遮挡背景，普通摄像头无法从无纹理表面获取深度信息，这是光学传感器的物理限制。
- **解决**：在水杯上贴有色胶带作为"光学标记"，使物体表面变得可检测。修复后水杯被清晰检测出来。
- **启示**：真实世界的感知系统需要冗余和工程妥协，纯粹依赖视觉算法存在局限性。

### 2. MiDaS 模型维度错误
- **问题**：transforms 预处理返回5维数据，导致 `Expected 3D or 4D input` 错误。
- **原因**：MiDaS 预处理函数与当前 PyTorch 环境不完全兼容。
- **解决**：放弃 transforms 库，手动实现图像缩放和归一化预处理，直接构造4维张量 `[1, 3, 256, 256]`。

### 3. Depth-Anything-V2 库代码缺陷
- **问题**：`depth-anything-v2` 库内部报 `'int' object is not iterable` 错误。
- **原因**：该 pip 包存在已知代码 bug。
- **解决**：改用本地缓存的 MiDaS PyTorch 权重（`midas_v21_small_256.pt`），配合手动预处理，稳定可靠。
