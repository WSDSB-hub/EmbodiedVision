# 01 - Hardware Setup

## 核心控制器
- 主控：STM32F103C8T6（江科大版核心板）
- 下载器：ST-Link V2

## 驱动与执行
- 电机驱动：TB6612FNG双路驱动模块
- 电机：MG513P28直流减速电机 ×2（13线霍尔编码器，1:28减速比，12V）

## 传感器
- 摄像头：USB 1080P免驱摄像头
- IMU：BNO055姿态传感器（备用）

## 通信
- 串口：CH340 USB转TTL模块
- 蓝牙：HC-05蓝牙模块 ×2（带底板）

## 供电
- 电池：3S锂电池 12V 2200mAh
- 降压模块：LM2596 DC-DC
- 保护电容：50V 100μF电解电容
- 保护电阻：1kΩ 1/4W ×6

## 结构
- 底盘：两轮差速小车底盘（含万向轮）
