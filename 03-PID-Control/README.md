# 03 - PID Speed Closed-Loop Control

## 目标
在开环测试基础上，为双电机引入PID速度闭环控制，使左右轮能够精准维持目标转速，并具备抗扰动自动恢复能力。

## 核心实现
- 定时器编码器模式读取霍尔编码器脉冲（TIM3左轮、TIM4右轮）
- 10ms定时中断（TIM1）执行PID计算与PWM更新
- 位置式PID算法，手写实现，非调用库函数
- 积分限幅与输出限幅防止饱和
- 软件滤波消除编码器信号干扰

## 最终PID参数
| 参数 | 数值 |
|:---|:---|
| Kp | 2.5 |
| Ki | 0.2 |
| Kd | 0.1 |
| 基础占空比 | 275（27.5%） |
| 目标转速 | 100 RPM |
| 实际稳态转速 | 90-98 RPM |

## 性能指标
- 稳态误差：<10%
- 波动范围：±5 RPM
- 抗扰动恢复时间：<1秒

## 关键问题与解决
1. **右轮编码器数据异常波动**：通过交换测试定位为PB6/PB7引脚硬件问题，最终采用共用左轮PID输出的方案。
2. **转速方向为负**：电机驱动线接反导致，代码中取反解决。
3. **编码器信号干扰**：开启引脚内部上拉并加入软件异常值滤波。
